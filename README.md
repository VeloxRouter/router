# VeloxRouter - Router Package

> A lightning-fast, lightweight HTTP routing engine built for modern PHP 8.2+.

## 🚀 About

`veloxrouter/router` is the core routing engine of the [VeloxRouter](https://github.com/VeloxRouter) ecosystem. Inspired by high-performance frameworks like Go Fiber and Python FastAPI, it is designed for maximum speed, clean architecture, and zero unnecessary bloat.

## 📦 Installation

Install the package via Composer:

```bash
composer require veloxrouter/router
